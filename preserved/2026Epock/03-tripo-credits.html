Tripo3D 크레딧 2,825 활용 전략

만료 전 확보할 3D 자산의 우선순위와 예산 이력

이 문서는 대화에서 논의한 설계안과 후속 검증 내용을 재구성한 기록입니다. 초기 가정과 실제 확인된 사실을 구분하며, 구현·라이선스는 추가 검증이 필요합니다.

01. 초기 구상

초기에는 HD 생성 15크레딧 가정으로 약 150개 표준 자산과 예비비를 계획했다. 생애주기 인물, 동물, 일상 사물, 자연·건축 부품을 확보해 Blender에서 카메라·조명·포즈 변형으로 10,000장 이상 렌더링하는 구상이었다.

02. 실험으로 확인된 변경

실제 사용자는 Smart Mesh에서 생성 개수와 무관하게 한 요청당 100크레딧이 소모되는 것을 확인했다. 따라서 HD 기준 150개 예산안은 현재 실행안이 아니다. 2,825크레딧은 100크레딧 요청 최대 28회(잔여 25)라는 예산 상한을 제공한다. 요청당 결과 후보 수와 실제 다운로드·리깅 비용은 별도 확인해야 한다.

03. 선별 원칙

정적 의자·책상·바위보다 리깅·포즈 변화가 필요한 인체·동물·특수 조형 원형에 크레딧을 우선 배정한다. 비슷한 메시를 반복 생성하기보다 서로 다른 관절 구조, 극단적 머리 실루엣, 동물 체형, 짧은 사지와 장신형을 확보한다.

04. 확장성

원천 메시 1개에서 8시점×3조명×2배경 등 48장 이상 파생 가능하다. 다만 이미지 수가 곧 독립적인 정보량을 의미하지 않는다. 같은 메시에서 나온 렌더링은 train/validation 간 분리하지 않는다.

05. 데이터 주권과 라이선스

A-CORE는 창작자가 직접 모델링한 기하학적 원본으로, A-WORLD는 Tripo 등 외부 생성 도구의 영향을 받은 자산으로 분리한다. Tripo 출력물을 다른 생성 모델 학습에 사용할 권한은 약관과 서면 허가로 별도 확인해야 한다. AI 생성 3D를 100% 직접 모델링 데이터라고 표기하지 않는다.

06. 보존

3면도 원본, 생성 프롬프트, 작업 ID, 생성 일시, 비용, 메시, FBX/GLB, 라이선스 근거, Blender 수정 이력을 자산별로 보존한다.
