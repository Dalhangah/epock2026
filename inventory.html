목표와 핵심 원칙

하나의 리깅된 3D 포즈를 여러 카메라에서 렌더링하여 인체 윤곽, 구조선, 혼합 도형화, 동세선, 검정 실루엣의 5종 대응 이미지를 생성한다. 각 결과에는 3D 공간정보, 2D 투영좌표, 자연어 캡션을 결합한다. 학습 단위는 character × action × resolved_pose × camera × render_style이다.

제품 사용 시나리오

웹툰 밑그림, 동세→인체 복원, 박스 도형→인체 윤곽, 구도 제어, 작품 초반 실루엣 연출, 캐릭터 체형별 동작 생성, 비인간형 확장이 주요 사용 시나리오다. 완성 의상·얼굴·채색은 초기 학습 목표에서 제외한다.

동세 입력→인체 러프

캐릭터·카메라 조건→구도 생성

인체 윤곽→도형화 페어

포즈→실루엣

캐릭터 분류

종족(species)과 골격 계열(rig_family)을 분리한다. 인간형, 사족보행, 조류, 혼합형이 골격의 초기 범주다. 같은 토끼라도 사족보행 토끼와 의인화 토끼는 다른 골격을 사용할 수 있다.

species: human/rabbit/cat/bird/other

rig_family: humanoid/quadruped/avian/hybrid

locomotion: biped/quadruped/flight/mixed

character_id, rig_profile_id, style_family_id

등신비와 체형

head_count는 전체 신장을 정수리~턱 길이로 나눈 연속값으로 저장한다(귀·뿔 제외). 분류는 1.5~2 super_SD, 2~3 chibi, 3~4 SD, 4~5 stylized, 5~7 semi_realistic, 7~10 realistic/heroic로 제안한다.

body_build와 muscularity를 분리

muscle_definition, body_fat, 어깨·골반 폭 저장

head_scale/hand_scale/foot_scale/limb_scale 저장

인종·민족은 제작자가 명시한 설정만 선택적으로 기록; 외형에서 자동 추정 금지

동작 의미와 포즈의 분리

action_id는 달리기·머리 만지기·포옹 등의 의도이며 pose_id는 특정 캐릭터 골격에서 계산된 실제 관절 상태다. 같은 동작을 2등신과 8등신에 동일한 관절 각도로 적용하지 않는다.

동작별 접촉 표면·지지점·시선·동작 방향 기록

골격 계열별 지원/대체/불가 정책

키프레임과 속도 선택적 저장

표준 Armature와 본 매핑

기존 Armature를 공유하면서 표준 의미 본 이름을 실제 본에 매핑한다. Mixamo·Rigify 등 다양한 이름 체계에 대한 rig_profile을 유지한다. 원본 인체 메시와 도형화 메시를 같은 포즈로 움직이게 한다.

humanoid: pelvis/spine/chest/head/arms/legs

quadruped: spine/front legs/hind legs/tail

avian: wings/legs/neck/head

Rest Pose·본 축·좌우·스케일·부모 체인 검증

컨트롤 본과 deform 본 구분

리타기팅과 충돌 보정

동작 의도→골격 매핑→신체 비율 정규화→IK 목표 재계산→관절 제한→충돌·접지·균형 검사→pose_id 확정으로 처리한다. 손이 머리를 만지는 동작은 고정 월드 좌표가 아닌 머리 표면 상대 목표로 정의한다.

손-머리/팔-몸통/다리-골반 관통 검사

인물-인물/인물-환경 충돌 검사

의도된 접촉 허용·관통 깊이 제한

실패 포즈는 검수 큐로

카메라 좌표계와 구도

Blender Z-up을 사용하되 캐릭터 local_forward를 별도 기록한다. 정면·측면 카메라는 고정 기준축으로 정의하고 자유 시점과 구분한다. 월드 좌표뿐 아니라 카메라-캐릭터 상대 변환을 저장한다.

matrix_world 4×4/position/quaternion/Euler

PERSP/ORTHO, lens_mm, sensor_width/height, sensor_fit

shift_x/y, clip_start/end, ortho_scale

방위각·고도각·롤·피사체 거리

2D bbox·점유율·잘림·관절 가림

투영 좌표와 화각

관절 3D 월드 좌표를 카메라 이미지 평면의 정규화된 2D 좌표로 투영한다. 시야각은 렌즈·센서 크기·sensor_fit을 고려한다. 수평 센서 기준 FOV = 2 atan(sensor_width/(2×lens_mm)). 50mm 키워드만으로 정확한 원근감이 보장되지는 않는다.

각 관절 x/y 정규화 좌표·깊이·가시성 저장

캐릭터 화면 중심·bbox·점유율 계산

프레이밍 태그는 실제 투영 결과에서 생성

조명과 재현성

조명 type/location/rotation/energy/color/size와 월드 배경, 렌더 엔진, 샘플, 색 관리, Blender 버전, 자산 해시, 시드를 기록한다. Emission 기반 선화와 실루엣에서는 조명보다 카메라·포즈가 우선 조건이다.

렌더 설정 버전·엔진·시드 기록

조명 수치·월드 설정 저장

원본 blend 및 자산 버전 추적

A: 인체 윤곽형

흰 배경에 진회색 또는 검정 외곽선만 남긴다. 실제 인체 실루엣과 필요한 겹침 경계는 유지하되 의상·피부 텍스처·불필요한 명암은 제거한다.

메인선 두께 정책 통일

원본 의상 메시가 결합된 경우 자동 제거 불가 플래그

B: 인체+가이드형

A형의 동일한 윤곽에 연회색 머리 방향축, 척추·몸통 중심선, 어깨·골반 축, 관절 위치 및 단면선을 추가한다. 메인선보다 가이드선을 약하게 표시한다.

가이드 레이어 분리

선 두께·색·가시성 토글

같은 포즈·카메라 유지

C: 혼합 도형형

EPOCK_HYBRID 컬렉션을 별도 생성하고 같은 Armature를 공유한다. 머리는 타원체, 흉곽·골반은 박스, 팔다리는 테이퍼 원기둥, 관절은 구체, 손발은 단순 박스로 표현한다.

기존 인체 Decimate만으로 대체하지 않음

본 방향에 도형 정렬

관절 단면과 중심축 가이드 추가

D: 동세선형

정면·측면의 최소 골격과 자유 카메라 투영 스틱맨을 생성한다. 관절 연결선과 Line of Action(움직임의 흐름)은 분리한다. 무게중심·지지점·골반 기울기를 표현한다.

관절 위치 기반 연결선

척추 흐름 곡선은 별도 계산·검수

2D 동세만으로 3D 포즈를 유일하게 복원할 수 없음

E: 검정 실루엣형

검정 Emission 재질과 흰 배경으로 내부 디테일 없는 순수 실루엣을 출력한다. 두 인물이 겹치면 하나의 덩어리가 되므로 개별 인물 마스크도 별도로 보존한다.

instance_mask 필수 권장

body_part_mask/depth/normal 선택

소품 포함 여부 정책화

ID 및 파일 구조

scene_id는 장면, character_id는 자산, action_id는 동작 의미, pose_id는 실제 관절 상태, camera_id는 카메라, sample_id는 장면·포즈·카메라 조합을 식별한다. schema_version을 모든 메타데이터에 부여한다.

키워드 자동 생성

자연어 캡션은 상대 방위각, 고도각, 렌즈 FOV, 인물 화면 점유율, 바운딩박스, 캐릭터 방향, 포즈 의미로부터 생성한다. 각 태그의 수치 경계는 버전 관리한다.

front/side/three_quarter/back

high/eye_level/low_angle

full_body/medium/close_up

left/center/right

cropped/occluded/multi_person

head_count, rig_family, build, action

학습 설계

동세→인체, 도형화→인체, 동세→실루엣, 카메라 조건→다중 시점 생성을 별도 실험으로 구분한다. 텍스트 키워드만으로 정밀한 시점 제어가 보장되지 않으므로 수치 카메라 조건과 관절 입력을 함께 사용하는 모델 구조를 검토한다.
