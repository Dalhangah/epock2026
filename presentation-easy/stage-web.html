독자가 함께 보는 SNS 웹툰을 만들어요

프로젝트 기록을 읽는 아카이브는 공개되어 있습니다. 작품을 체험하는 기능과는 구분해야 합니다. 현재 artwork 화면은 샘플이며, 실제 독자 서비스가 모두 완성되었다는 뜻은 아닙니다.

작품 속 시간을 골라요

작품 속 시간은 2120년부터 2126년까지입니다. 독자가 시간을 바꾸면 그때까지 올라온 자매의 SNS 게시물과 스토리를 볼 수 있게 할 계획입니다. 아바타를 운영하는 사람은 인간 자매입니다. 아바타가 독립된 인격은 아닙니다. 1에폭은 작품 속 하루와 연결하며, 이번 범위에 큰 사건과 결말은 넣지 않습니다.

만들 기능

  • 선택한 시점의 게시물과 24시간 스토리 보기.
  • 원하면 로그인하거나 임의 닉네임으로 반응 남기기.
  • 댓글·좋아요와 과거 시점에 생긴 새 댓글 알림.
  • 배경·인물·효과음·말풍선을 나누어 보여 주기.
  • 컷과 말풍선 번호에 연결된 언어별 대사와 공식 언어 버튼.

실제 자료가 아직 없으면 시연용 자료라고 표시하여 화면을 시험합니다. 아카이브 문서가 공개되었다고 로그인·댓글·알림 기능까지 완성된 것은 아닙니다.

웹 화면과 이미지 생성은 다른 서버가 맡아요

이 페이지의 예전 기록에는 가비아 Python 호스팅 계획이 있었습니다. 이후 전체 시스템 설계에서는 PHP와 CodeIgniter 4로 웹서비스를 만들고, 이미지 생성은 별도의 Python 서버에 요청하는 방향을 선택했습니다. 새 결정이 과거 계획으로 되돌아가지 않도록 구분합니다. 실제 배포와 서버 간 연결은 시험해야 합니다.
