학습 전에 컴퓨터 환경을 확인했어요

2026년 11월 10일 오후 10시 57분 21초에 시작한 Colab 환경 진단 기록입니다. 같은 날 오후 10시 59분 47초에 저장된 노트북 출력을 확인했습니다. 모델을 학습하거나 그림을 생성한 시험은 아닙니다.

확인된 준비 상태

  • Tesla T4라는 GPU가 배정되었습니다. GPU는 많은 계산을 빠르게 처리하는 장치입니다.
  • PyTorch가 읽은 메모리는 약 14.56 GiB이고 CUDA를 사용할 수 있었습니다. 다른 장치 조회 도구는 15,360 MiB를 표시했습니다. 도구마다 표시 방식이 다릅니다. 다음 세션에도 같은 장치를 받는다는 뜻은 아닙니다.
  • Google Drive를 연결하고 지정한 프로젝트 폴더가 있는 것을 확인했습니다.
  • Python과 라이브러리 버전 확인, 진단 JSON을 Colab의 임시 저장공간에 저장했다는 출력이 있습니다.

아직 하지 않은 것

  • Drive에 새 파일을 쓰고 다시 읽는 시험은 꺼져 있었습니다. 폴더가 보인다고 쓰기까지 검증된 것은 아닙니다.
  • 샘플 이미지 경로를 지정하지 않아 이미지 검사를 하지 않았습니다.
  • 진단 JSON 다운로드도 꺼져 있었습니다. 별도 JSON 파일을 회수하여 대조하지 않았습니다.
  • 모델 학습·그림 생성·체크포인트 저장과 복구·웹 전달은 이 진단의 범위가 아닙니다.

프로그램 기록된 버전
Python 3.13.16

xFormers 설치 정보 없음

설치되어 있다는 것과 학습 코드가 잘 작동한다는 것은 다릅니다. xFormers가 없다는 이유만으로 진단 실패라고 판단하지 않습니다.

무엇을 고쳤나요?

처음에는 Drive 연결 설정이 꺼져 있었습니다. 성공이라는 글자만 바꾸면 실제 연결 없이도 성공처럼 보일 수 있어, 연결 결과와 폴더 존재를 확인하도록 고쳤습니다. 경로는 코드 맨 위에 모으고 같은 변수를 함께 사용하도록 했습니다.

기록 기준은 PIPELINE-DIAG v0.1.0 사용자 수정본입니다. 따로 제안한 v0.1.1의 모든 내용이 반영되었다고 단정하지 않습니다. 당시 공통 기준 표기는 EP-CORE-001 v1.2.0입니다.

다음에 확인할 것

필요할 때 새 파일 쓰기·읽기를 시험하고 진단 기록을 오래 남는 저장소에 보관합니다. Colab 임시 파일은 세션이 끝나면 사라질 수 있습니다. 소량의 실제 자료로 짧게 학습하여 메모리, 프로그램 호환, 저장과 복구를 별도로 확인합니다. 개인 계정·인증정보와 원시 출력은 이 페이지에 공개하지 않습니다.
