초기 기획 문서 여섯 개

옛 기획을 읽는 방법

당시 묶음 이름은 “2026 EPOCH 두 생명의 성장기”였습니다. Tiny-Diffusion A와 SD 1.5 B, 창작자가 학습자료를 관리할 권리, 캐릭터 형태를 만드는 규칙, 학습 과정의 예술 기록을 함께 다뤘습니다. 아래는 초기 설계의 구성입니다. 지금 모두 구현되었다는 뜻은 아닙니다.

문서 1: AI와 함께 일하는 방법

ChatGPT Pro를 기획, 연구, 코드 작성, 확인 작업에 어떻게 활용할지 정리했습니다.

문서 2: 두 모델을 학습시키는 방법

Colab에서 A와 B 모델을 시험하고, 그림과 학습 기록을 이야기로 이어 가는 초기 계획입니다.

문서 3: 3D 생성 비용을 쓰는 방법

Tripo3D에 남아 있는 2,825크레딧을 어떻게 사용할지, 실제 시험 뒤 예산 계산이 어떻게 바뀌었는지 다뤘습니다.

문서 4: 캐릭터의 형태를 설명하는 방법

머리와 몸의 비율, 몸통 모양, 관절, 자세와 카메라를 기록하는 기준을 만들려 했습니다.

문서 5: 3D 기본 모델을 고르는 방법

움직이기 좋은 모델과 다양한 형태의 기본 틀을 먼저 확보하는 계획입니다.

문서 6: 시간이 부족할 때 준비하는 순서

이용 기간이 끝나기 전에 만들 일과 나중에 Blender에서 고칠 일을 나눴습니다. 파일 이름에 있는 v1.0, v2.0 등의 버전은 당시 문서 이름을 그대로 남긴 것입니다.
