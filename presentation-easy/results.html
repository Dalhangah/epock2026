일곱 단계로 살펴보기

기획, 설계, 학습 자료 만들기, 작업 연결, 학습, 이미지 생성, 인터랙티브 웹툰 완성의 일곱 단계입니다. 모두 같은 깊이의 단계이며 서로의 하위 단계가 아닙니다. 여러 작업은 동시에 진행할 수 있습니다.

원본 첫 화면은 2026년 11월 15일 무렵의 요약입니다. 이후 실행 기록도 생겼으므로 아래의 “대기”를 지금까지 한 번도 실행하지 않았다는 뜻으로 읽지 마세요. 최신 상세 기록과 구분해서 보존합니다. 완료율 하나로 모든 작업을 평가하지 않습니다.

1. 기획: 작품이 묻는 질문 정하기

AI 학습과 자매가 아바타를 만드는 이야기를 연결합니다. 작품의 질문, 연구와 작품을 잇는 기준, 저장과 재개 방향, 초기 창작 의도는 정리했습니다. 작품 전체 완성은 아닙니다.

2. 설계: 보여 줄 방법 정하기

자매가 직접 운영하는 SNS와 학습 한 차례를 작품 속 하루로 삼는 기준을 반영합니다. 몸의 형태와 시간 이동 화면을 연구하고 구체적인 제작 규칙, 아직 구현하지 않은 기능을 구분합니다.

3. 학습 자료 만들기

직선·호·자유곡선과 구도 설명 자료 1,640쌍을 만들었다고 기록되어 있습니다. 기본 인체를 고른 뒤 손과 관절 움직임, 손으로 그린 듯한 해칭, 그림 출력 품질을 점검합니다. 11월 13일 비교 결과도 남겼습니다. 자료가 있다고 모델이 이미 배운 것은 아닙니다.

4. 작업을 연결하기

학습 기록에서 이야기, 그림 지시문, 이미지, 웹 화면까지 연결하는 구조를 만듭니다. Blender로 만든 자료를 Colab이 읽게 하고, 각 도구의 역할과 모델이 실제 받을 수 있는 입력을 확인합니다.

5. 모델 학습

요약 화면에서는 Tiny-UNet VR0.02의 외부 자료 연결과 작은 실험을 준비하는 단계로 적혀 있습니다. 이후의 학습 시험은 별도 파이프라인 기록에서 버전별로 다룹니다. Stable Diffusion에서 쓸 체크포인트 제작은 별도 프로젝트입니다. Colab 장치 선택과 저장·재개 방향을 정한 것과 학습 품질 검증은 다릅니다.

6. 작품 이미지 생성

이야기를 그림 지시문으로 바꾸고 배경과 인물을 나누어 생성할 계획입니다. 연구 시안과 최종 작품 이미지를 구분하며 전체 제작 완료로 표시하지 않습니다.

7. 인터랙티브 웹툰 완성

연구 기록 사이트는 공개되어 있습니다. 작품 속 SNS와 시간 이동 화면, 여러 관객이 함께 쓰는 기능은 별도로 만듭니다. 11월 30일 공개를 목표로 준비하지만 공개 일정과 기능 완성은 다릅니다.
