초기 계획: 두 AI 모델을 시험하기

지난 설계안입니다

이 글은 AI 학습 시스템 개발 설계서 v1.0을 쉽게 풀었습니다. 당시의 두 모델 계획을 보존한 것이며, 지금의 결정이나 완성된 기능으로 읽으면 안 됩니다. 구현과 이용 권리는 추가 확인 대상입니다.

A와 B를 다르게 시작하려 했습니다

A는 미리 배운 모델 없이 시작하는 작은 U-Net 확산 모델입니다. 그림의 픽셀을 다루며, 처음에는 64×64 크기로 시험하고 128×128, 256×256으로 넓힐지 검토했습니다. B는 이미 학습된 SD 1.5를 바탕으로 512×512 그림을 추가 학습하는 계획이었습니다. B에서 먼저 검토한 LoRA는 일부 작은 추가 가중치를 학습하는 방법으로, 모델 전체를 다시 학습하는 방법과 다릅니다.

그림 준비부터 웹툰까지

직접 만든 Blender 모델에서 색 그림, 실루엣, 깊이 자료와 설명 정보를 만듭니다. 같은 원본 모델에서 나온 그림은 한 묶음으로 관리하며 학습용과 평가용이 섞이지 않게 합니다. 각 모델에 맞춰 자료를 준비한 뒤 학습하고, 같은 난수 시작값으로 그림을 만들어 비교합니다. 그 결과를 학습 차수별 기록으로 모아 웹툰 화면에 연결하려 했습니다.

작게 시작하는 시험

A는 직접 만든 3등신 인체 자료와 64픽셀 그림으로 짧게 학습하고 중간 상태를 저장하는 계획이었습니다. B는 같은 원본을 512픽셀로 출력해 LoRA가 작동하는지 먼저 확인하려 했습니다. 두 시험 모두 요청문, 난수 시작값, 모델 버전, GPU, 프로그램 버전, 실행 시간을 남기도록 했습니다.

계산 장비도 먼저 재 봅니다

Colab의 GPU 종류와 사용 시간은 보장되지 않습니다. 먼저 T4급 16GB 환경에서 작은 시험을 하고, 걸린 시간과 메모리 사용량을 보고 더 큰 장비가 필요한지 판단하기로 했습니다. 검토한 도구에는 Python, PyTorch, Diffusers, Accelerate, PEFT, Pillow, OpenCV, pandas, Blender, Git이 있습니다. 이들은 학습·그림 처리·기록을 돕는 프로그램들입니다.

이야기 속 시간과 실제 학습 횟수는 다릅니다

당시 작품에서는 1에포크를 이야기 속 한 달로 해석하려 했습니다. 실제 에포크는 학습자료 전체를 한 번 보는 횟수입니다. 자료 양과 구조가 다른 A와 B는 에포크 수만으로 누가 더 잘 배웠는지 비교할 수 없습니다. 오차, 그림 품질, 본 자료의 양, 계산량을 함께 봐야 합니다.

멈췄다가 다시 배우려면

모델의 값만이 아니라 학습을 조절하던 상태, 진행 횟수, 난수 상태도 중간 저장 파일에 담아야 합니다. 같은 시작값의 예시 그림, metrics.csv 같은 수치 기록, config.json 같은 설정, 자료가 바뀌었는지 확인할 값도 남기는 계획입니다. 외운 자료에만 맞아지는 현상과 다양한 결과를 만들지 못하는 현상을 같은 문제로 단정하지 않고, 숫자와 실제 그림을 함께 살핍니다.
