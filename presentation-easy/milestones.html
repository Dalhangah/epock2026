시작부터 공개까지의 일정

이 일정표를 읽는 방법

이미 한 일, 방향만 정한 일, 진행 중인 일, 앞으로 할 일을 나누었습니다. 정확한 날짜를 모르면 추측해서 넣지 않습니다. 앞으로의 작업 날짜는 제안이며 모두 끝내겠다는 약속은 아닙니다.

2026년 4월: 처음 생각을 남기다

개인이 만든 자료로 AI의 변화를 살펴보고, 윤리를 생각하는 창작 과정을 실험하려는 초기 기획이 있습니다. 문서가 있다는 뜻이지 모델이나 작품이 완성된 때는 아닙니다. 정확한 결정일은 확인하지 못했습니다.

5~9월 무렵: 계획을 다시 세우다

예산 규정에 맞춰 사업계획을 고치고 줄어든 제작 기간에 맞추었습니다. 당시 월별 계획은 현재 공개 일정과 구분합니다.

준비 과정: AI와 Blender를 배우다

작가는 아이펠을 수료하고 Blender 수업을 마쳤습니다. 보고서에는 9월 Blender 심화교육과 모델링·스크립트 활용 계획이 나옵니다. 교육 계획 날짜를 실제 수료일로 단정하지 않습니다.

10월 9일: 두 가지 배움과 이야기

처음부터 배우는 A와 이미 배운 기술을 쓰는 B를 대비하고, 학습을 이야기와 연결하며 작품 속 시간을 움직이는 구상이 구체화되었습니다. 당시 이름, 이미지 크기, 일정은 이후 결정과 구분합니다.

10월 13일과 10월 중간보고서

10월 13일 온라인으로 프로젝트 시작 모임을 했다는 기록이 있습니다. 10월 중간보고서에는 방향과 남은 작업을 담았습니다. 상세 이야기와 캐릭터 디자인, 자료 만들기와 모델링, 학습 연결은 아직 진행 중이거나 후속 작업이었습니다. 보고서 작성일로 발표 행사 개최일을 확정하지는 않습니다.

이후: 작품과 긴 연구를 나누다

이번 작품은 Tiny-UNet VR0.02 계열로 진행하고, Stable Diffusion에서 쓸 모델을 처음부터 만드는 목표는 별도 프로젝트로 나누었습니다. 결정한 정확한 날짜는 확인하지 못했습니다.

11월 5일 이후: 기록 방식도 정리하다

11월 5일 기획과 개발 전략을 웹 문서로 남기기로 요청했습니다. 그날 게시까지 끝냈다는 뜻은 아닙니다. 이후에는 최신 결과와 비하인드를 나누고 참여자별 기여를 표시했습니다.

배경·인물·대사를 분리하는 방식, 이미지와 JSON 설명 파일의 이름 맞추기, Excel 목록, 저장·재개 기록도 기준으로 정했습니다. 기준을 정한 것과 모든 기능 완성은 다릅니다.

11월 17~18일 무렵의 확인 지점

선과 구도 자료에서 평면·입체·인체 자료로 범위를 넓히고 있습니다. 3·4등신 기본형에서 동작, 손과 도구의 접촉, 그림 표현을 검수합니다. 자료가 있다고 학습까지 끝난 것은 아닙니다.

독립 시험 모델 SmokeNoiseNet으로 Dataset Selector v0.3을 2 epoch 실행한 기록이 있습니다. 학습 손실은 0.302304에서 0.163088로 줄었고 그림·숫자·학습 상태 저장과 모델·학습 조절 상태를 다시 읽는 것을 확인했습니다. 그림은 아직 잡음이며 평가 자료 분리, 정확한 이어 학습, 조건 제어는 미검증입니다. Tiny-UNet VR0.02 본학습 성과로 부르지 않습니다. 이후 버전의 더 최근 결과는 별도 파이프라인 기록을 봅니다.

학습 관찰에서 SNS 초안을 만들고 작가 검토 뒤 웹에 표시하는 흐름을 설계합니다. 실제 학습 시간, 작품 속 하루, 관객 접속 시간을 구분하며 여러 관객의 동시 사용은 따로 시험해야 합니다.

공개 전 작업 제안

11월 18일: 사용할 모델과 입력 자료, 짧은 학습·저장·재개, 조건 입력 범위를 확인하고 실행 기록과 오류 목록을 남깁니다.

11월 19~20일: 기록 한 묶음에서 SNS 초안, 작가 검토, 웹 표시까지 작은 샘플 하나로 이어 봅니다.

11월 21~23일: 실제 시간과 품질을 보고 공개할 자료를 고릅니다. 인체 생성이 부족하면 선·도형의 실제 변화로 범위를 조정할 수 있지만 작가가 결정합니다.

11월 24~26일: 승인된 콘텐츠와 시간 이동, 댓글, 여러 기기의 화면 갱신, 공개 시각을 연결해 휴대폰 여러 대로 확인합니다.

11월 27~29일: 카운트다운, 공개 전환, 모바일 감상, 소통과 후속 이벤트를 현장처럼 연습합니다. 연결이 끊길 때 쓸 대체 감상본과 운영 방법을 준비하고 공개본을 고정합니다.

11월 30일: 발표와 작품 공개

한국시간 오후 3시 발표회에서 기획과 제작 과정을 소개합니다. 오후 4시 30분 웹 작품을 공개하고 각자의 휴대폰으로 함께 감상하며 소통하는 것이 목표입니다. 이 시각은 작가가 정한 계획입니다. 자동 화면 전환, 실시간 소통, 후속 이벤트가 이미 시험까지 끝났다는 뜻은 아닙니다.
