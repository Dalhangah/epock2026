초기 계획: ChatGPT와 함께 개발하기

먼저 알아둘 점

이 글은 대화에서 만든 초기 설계와 뒤에 확인한 내용을 정리한 지난 기록입니다. 제안한 기능이 모두 완성되었다는 뜻은 아닙니다. 실행 방법과 자료를 사용할 권리는 따로 확인해야 합니다.

작품의 첫 생각

“에포크로 쓴 두 생명의 성장기”는 AI가 반복해서 배우는 시간을 삶의 시간에 빗대는 웹툰 구상입니다. 창작자가 자료와 설계를 관리하고, 두 모델이 달라지는 과정과 실패를 관찰해 이야기로 기록하려 했습니다.

AI에게 맡기려 한 여섯 가지 일

① 모델 구조와 시험 순서 정하기 ② Blender에서 학습 그림을 자동으로 만들 코드 쓰기 ③ 성장 이야기와 이미지 요청문 자료 만들기 ④ 학습 오차와 중간 저장 모델, 같은 조건으로 만든 그림 비교하기 ⑤ 독자가 참여하는 웹툰 만들기 ⑥ 윤리·이용 권리·연구 기록 정리하기입니다.

사람과 도구의 역할

ChatGPT Pro는 코드 작성, 설계 검토, 오류 찾기, 실행 기록 읽기, 문서 정리에 쓰려 했습니다. 많은 계산이 필요한 모델 학습과 그림 출력은 Colab이나 별도 클라우드 GPU에서 실행하는 계획입니다. GPU는 계산을 빠르게 돕는 장치입니다. ChatGPT 구독료와 OpenAI API 사용료는 따로입니다.

일을 나누되 기준은 함께 쓰기

모델 연구, Blender 자동화, Tiny-Diffusion, SD 1.5 추가 학습, 이야기, 웹툰 화면, 실험 기록을 별도 작업으로 나누려 했습니다. 대신 공통 기준, 버전, 결정한 내용은 함께 관리합니다. 이 목록은 당시의 작업 구분이며, 현재의 모든 목표를 확정하는 목록은 아닙니다.

코드가 생겼다고 성공한 것은 아닙니다

먼저 적은 자료로 작게 실행해 봅니다. 실행 기록, 나온 그림, 다시 실행할 때 필요한 조건을 남깁니다. 측정으로 확인한 사실과 작가가 이야기로 해석한 내용도 서로 구분합니다.
