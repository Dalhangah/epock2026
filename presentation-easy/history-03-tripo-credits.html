초기 계획: 3D 생성 비용을 어디에 쓸까요?

당시 예산을 고친 기록입니다

Tripo3D의 2,825크레딧을 만료 전에 어떻게 쓸지 검토했던 기록입니다. 크레딧은 서비스에서 작업할 때 쓰는 이용 단위입니다. 아래 비용은 당시 사용자의 시험과 계획에 관한 것이며 현재 요금표는 아닙니다.

처음 계산은 달랐습니다

처음에는 HD 생성에 15크레딧이 든다고 가정해 약 150개 기본 자산과 예비 비용을 생각했습니다. 나이별 인물, 동물, 생활 사물, 자연·건축 부품을 만들고 Blender에서 시점·조명·자세를 바꿔 1만 장 이상 그림을 뽑는 구상이었습니다.

직접 시험하니 요청 한 번에 100크레딧이 들었습니다

사용자는 Smart Mesh에서 생성 개수와 관계없이 한 요청에 100크레딧이 쓰이는 것을 확인했습니다. 따라서 처음의 150개 예산안은 실행 기준에서 제외했습니다. 2,825크레딧이면 이런 요청은 최대 28번이고 25크레딧이 남습니다. 한 요청에서 쓸 만한 결과가 몇 개 나오는지, 다운로드와 관절 작업에 추가 비용이 있는지는 별도 확인해야 합니다.

움직임과 형태가 다른 모델을 우선하기

의자·책상·바위처럼 움직이지 않는 사물보다 관절과 자세를 바꿔야 하는 사람·동물·특별한 형태에 먼저 비용을 쓰려 했습니다. 비슷한 모델을 반복하기보다 관절 구조, 머리 윤곽, 동물의 몸, 짧은 팔다리와 긴 몸처럼 차이가 큰 기본형을 고릅니다.

그림 수와 정보의 양은 다릅니다

모델 하나를 8방향, 조명 3가지, 배경 2가지로 찍으면 48장을 만들 수 있습니다. 하지만 48개가 모두 전혀 새로운 모양은 아닙니다. 같은 모델의 그림이 학습용과 평가용 양쪽에 섞이면 제대로 배웠는지 판단하기 어려워집니다.

직접 만든 자료와 외부 도구 자료를 나눕니다

A-CORE는 창작자가 직접 만든 도형 원본, A-WORLD는 Tripo 같은 외부 생성 도구의 영향을 받은 자료를 뜻하는 구분입니다. Tripo 결과를 다른 생성 모델의 학습에 써도 되는지는 약관과 필요한 서면 허가를 따로 확인해야 합니다. AI로 만든 3D를 전부 직접 모델링했다고 적지 않습니다.

함께 보관할 정보

앞·옆·뒤 그림, 요청문, 작업 번호, 생성 시각, 비용, 3D 메시, FBX·GLB 파일, 이용 권리 근거, Blender에서 고친 내역을 모델별로 남기려 했습니다. 메시란 3D 형태를 이루는 점과 면의 모음입니다.
