배우는 시간도 작품이 될 수 있을까요?

EPOCK은 어떤 작품인가요?

EPOCK은 AI가 그림을 배우는 과정을 이야기와 이미지로 보여 주는 웹툰 프로젝트입니다. 완벽한 그림만 보여 주는 대신, 선 하나를 만들기까지의 시도와 실패도 작품의 재료로 삼습니다. 지금은 연구와 제작을 진행하고 있으며 완성 작품 공개 전입니다.

에포크(epoch)는 AI가 준비한 학습 자료를 한 차례 살펴보는 단위입니다. 작품에서는 이 시간을 사람이 배우고 자라는 모습에 빗대어 표현합니다. AI의 숫자가 실제 감정이나 인생을 뜻하는 것은 아닙니다.

서로 다른 방법으로 아바타를 만드는 자매

한쪽은 기초부터 조금씩 배우고, 다른 한쪽은 이미 쌓인 기술을 활용합니다. 두 출발점은 다르지만 “창작의 가치는 좋은 결과만으로 정해질까?”라는 같은 질문을 던집니다.

Tiny는 단순하고 알아보기 쉬운 모습, Luxy는 화려하고 정교한 모습을 생각하고 있습니다. 옛 소개의 Ruxy는 이후 Luxy로 바로잡았습니다. 이 디자인 방향은 완성된 학습 모델이 만들어 낸 결과가 아닙니다.

학습 중에는 자매가 자기 아바타를 만드는 이야기를 다룹니다. 인간 자매의 전체 이야기와 결말은 작가가 결정합니다. 이번 공개 범위는 아바타 제작 과정과 SNS 운영이며, 큰 사건과 결말은 다음 프로젝트로 나눕니다.

관객은 어떻게 보나요?

작품 속 2120~2126년의 시간을 움직이며 SNS 기록과 아바타의 변화를 살펴보는 방식을 구상하고 있습니다. 그림의 배경, 인물, 말풍선도 따로 다룰 계획입니다.

지금 하는 일

캐릭터의 몸 비율과 구조를 비교하고, 학습에 쓸 그림을 만들고 있습니다. 11월 13일에는 정면 샘플에서 외곽선과 입체 표현이 나아진 것을 확인했지만, 만화식 명암과 그림 설명 기록은 더 점검해야 했습니다.

전체 목표는 자료 준비 → 모델 학습 → 변화 기록 → 이야기와 그림 지시문 만들기 → 그림과 웹 화면으로 이어집니다. 이 순서를 정했다는 것이 모든 과정의 자동 연결을 끝냈다는 뜻은 아닙니다.

결과 뒤에 있는 사람과 선택

작가는 이 작품을 위해 아이펠과 Blender 수업을 마쳤습니다. 작품 완성과 장기 모델 연구를 나누고, 여러 비율로 바꾸기 쉬운 기본 인체도 직접 만들었습니다. AI의 잘못된 제안이나 코드 오류는 작가의 시행착오와 구분해 기록합니다.
