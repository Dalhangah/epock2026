박항아 · 작가의 작업 방식

방향과 판단은 작가가 맡고, 이제에게는 지식의 정리와 계획·구현의 보조를 맡깁니다.

질문을 구체적인 작업으로 · 학습 과정으로 작품을 만든다는 구상을 대화로 점검하고, 필요한 데이터·코드·서사·웹 구현의 작업을 나눕니다.

대화를 역할별로 분리 · 한 대화에 모든 작업을 섞지 않고 서사, 세계관, 프롬프트, 웹 구현, UI/UX, 학습데이터와 Blender 스크립트 등의 대화로 나눕니다. 이제에게 각 대화의 시작문과 공통 기준을 정리하도록 요청합니다.

초안을 받고 직접 확인 · 코드와 문서를 한 번에 완성품으로 받기보다 수정 셀과 실행 결과를 하나씩 확인합니다. Blender 출력과 Colab 실행 결과를 공유하고, 의도와 다른 설명이나 이미지는 다시 수정하도록 요청합니다.

작품의 기준은 직접 선택 · 모델 호환성 목표와 작품 일정을 분리하는 결정, 기본 인체의 선택, 렌더 품질에 대한 판단은 작가가 합니다. AI의 제안을 그대로 프로젝트의 확정 사실로 삼지 않습니다.

기록을 관객의 언어로 · 대화를 그대로 공개하기보다 최종 방향과 현재 상태를 먼저 보여주고, 과정은 비하인드로 정리하도록 요청합니다. AI의 오류가 작가의 경험으로 오해되지 않도록 기록의 주체도 구분합니다.

작가가 이 대화에서 요청하고 직접 확인한 작업 방식을 정리한 글입니다. 작가의 직접 인용문이나 모든 자동화가 구현되었다는 설명은 아닙니다.
