원자료와 현재 설계

처음의 의도는 이어가고,
새로 정한 방향은 되돌리지 않습니다.

초기 아이디어와 10월 기술 검토를 현재 결정과 대조한 기록입니다. 자료를 읽은 날짜가 그 자료의 내용이 최신이라는 뜻은 아닙니다.

01지금 적용할 기준기록

A · 사전학습 없이 기초부터

VR0.01은 사전학습 VAE·CLIP을 활용한 기존 초안으로 보존합니다. 현재 승인된 VR0.02는 이를 제외한 작은 픽셀 확산 실험입니다. 빈 화면·색·선·도형에서 인체 도형화로 확장할 가능성을 확인합니다.

B · SD 1.5 캐릭터 LoRA

현재 대화에서 정한 학습 방향을 유지합니다. 10월 자료의 CPT·강한 과적합 전략은 당시 검토안이며, 현재 구현을 자동으로 그 방식으로 변경하지 않습니다.

기록에서 작품으로

학습 중에는 자매가 아바타를 만드는 과정을 기록합니다. 인간 자매의 전체 서사는 학습 결과를 보고 작가가 확정합니다. 수치에서 감정을 직접 판정하지 않습니다.

끊겨도 이어가는 학습

학습시간 계산, 런타임 종료 전 저장, 저장 상태를 불러와 이어 학습하는 것은 초기부터 계획한 운영 방향입니다. 실제 저장·복원 성공은 별도 실행 기록으로 검증합니다.

02과거 사양을 현재 확정값으로 옮기지 않습니다기록
  • 초기 자료의 해상도, 동작·앵글 수, 이미지 수, 배치 크기와 예상 에폭 수는 당시 가정입니다.
  • 매 epoch를 작품 속 한 달로 대응시킨 초기 규칙은 현재 시간축에 자동 적용하지 않습니다.
  • 2D 도형과 입체 표현을 배우는 기초 실험, 다양한 체형의 AI 이미지·3D 메시를 다듬는 인체 자료 준비를 구분합니다.
  • 카툰 렌더링, 최종 캡션과 모델 학습의 완료 여부는 각각 확인합니다.
03기술 문서를 읽을 때의 검증 경계기록

호환성·시간·비용

SD와의 완전 호환, 고정 시간 내 학습 완주, 고정 GPU 메모리·컴퓨팅 단위 소비는 현재 검증된 결과가 아닙니다. 실제 구조, 장치 배정과 실행 로그를 기준으로 판단합니다.

권리·학습 해석

직접 제작한 데이터도 사용 도구·자산의 출처와 이용 조건을 확인합니다. ‘저작권 위험 0%’를 보장하지 않습니다. 과적합과 모델 붕괴를 동일시하거나 학습 손실을 인격·감정·성장률로 읽지 않습니다.

초기 예시 코드의 UNet 한 번 호출은 완전한 확산 샘플링과 다릅니다. 반복 노이즈 제거, 조건 입력, 저장·재개와 품질 평가를 각각 시험해야 합니다. 가중치만 저장한 파일은 최적화 상태까지 복구하는 체크포인트와 구분합니다.

04읽은 자료와 보존 원칙기록

초기 프로젝트 아이디어, 10월 프로젝트 기획안, 기술 검토, 베이스 모델·파이프라인 가이드를 대조했습니다. 자료에는 작가의 요구와 AI가 작성한 설명이 함께 있으므로, AI 답변의 수치·보장 표현을 실제 성과로 취급하지 않습니다.

최신 사용자 결정 → 확인된 코드·실행 자료 → 날짜가 있는 원기획 → 과거 제안 순서로 구분합니다. 초기 문서의 의도를 삭제하지 않고 변경 이유를 남깁니다. 이전 문서를 자동 덮어쓰지 않습니다.

공유받은 원문과 이미지를 일괄 공개하지 않았습니다. 공개 페이지에는 프로젝트 설명에 필요한 요약과 현재 적용 기준만 반영했습니다.
