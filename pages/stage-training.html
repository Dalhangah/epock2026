현재의 학습 방향

Tiny 디퓨전

기본 형태와 학습 과정의 변화를 살펴보기 위한 학습을 계획합니다. 실제 설정·실행 기록이 확인되기 전에는 성능이나 완성도를 단정하지 않습니다.

Stable Diffusion LoRA

후속 대화에서 정한 LoRA 학습 방향입니다. 10월 중간보고서의 SD 1.5 CPT 표기는 당시 기획으로 별도 보존합니다.

학습 완료, 모델 성능, 편향 해결을 입증하는 결과는 이 페이지에서 제공하지 않습니다.

Colab과 가속기 선택

Colab 선택 배경과 A100 중심의 실험 제안을 별도 기록에 정리했습니다. 가속기 추천과 실제 배정·학습 실행 결과는 다릅니다.

기획 단계부터 정한 저장·재개 방향

학습에 걸릴 시간을 계산해 Colab 런타임이 종료되기 전에 가중치를 저장하고, 저장한 가중치를 다시 불러와 이어 학습하는 방향으로 기획했습니다.

사용자가 확인한 기존 설계 방향입니다. 저장·불러오기·학습 재개가 실제 코드에서 성공했다는 실행 결과와는 구분합니다.

실행 후 함께 공개할 기록 · 제안

  • 데이터 구성, 모델·학습 설정과 코드 버전
  • 실제 장치, 학습 스텝·에폭, 저장·재개 결과
  • 수치 기록과 같은 조건의 생성 샘플

원시 loss만으로 서로 다른 모델의 우열이나 등장인물의 감정을 판단하지 않습니다.

Tiny 실험의 현재 선택

VR0.01 · 기존 초안 보존

작은 UNet을 새로 학습하되 SD 1.5의 사전학습 VAE와 CLIP을 활용하는 코드입니다. UNet의 무작위 초기화와 시스템 전체의 비사전학습은 다릅니다.

VR0.02 · 승인된 실험 방향

사전학습 VAE·CLIP 없이 작은 픽셀 공간 확산 모델로 빈 화면, 색, 선과 도형부터 시험합니다. 인체 데이터가 준비될 때 확장 가능성을 평가하고, 충분하지 않다면 대안을 비교합니다.

미확정 실험은 소수점 이하 버전으로 관리합니다. VR0.02 방향의 채택은 학습 수렴이나 인체 생성 성공을 뜻하지 않습니다. 사전학습 가중치가 없어도 구조·데이터·조건·학습 순서는 사람이 설계합니다.
