배경과 인물

컷 전체를 한 번에 이미지로 고정하지 않고, 배경과 각각의 인물을 분리해 생성하는 방향입니다.

효과음과 대사

효과음은 웹폰트를 활용한 투명 PNG로, 대사는 지정 폰트의 텍스트로 표현하는 구상입니다. 말풍선 종류와 꼬리는 컷·인물 위치에 맞춥니다.

요소 분리 제작의 계획이며, 최종 작품 이미지나 자동 생성 시스템이 완성되었다는 뜻은 아닙니다.

04 / CONNECTING THE WORK

연구와 작품을 연결하는 기준

학습 중 기록할 이야기

자매가 각각의 아바타를 만들어 가는 과정. 수치와 생성 결과를 참고하되, 수치 자체를 감정이나 성장률로 단정하지 않습니다.

학습 이후 확정할 이야기

인간 자매가 등장하는 전체 서사. 학습 결과를 살펴본 뒤 작가가 확정하며, 자매 장면은 실루엣으로 표현할 계획입니다.

기술 내용을 더 확인하고 싶다면

A/B 모델의 입력 조건과 학습 설정은 실제 구현 단계에서 확인해야 합니다. 두 모델의 원시 loss를 그대로 비교해 우열이나 감정으로 해석하지 않습니다.

10월 보고서의 SD 1.5 CPT 표기와 후속 LoRA 학습 방향은 서로 구분해야 합니다. 보고서 원문은 당시 기획으로 보존하고, 새 실행 결과가 확인되면 해당 설정과 함께 별도로 공개합니다.
