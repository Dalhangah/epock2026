06인물과 SNS · 이번 작품에서 보여줄 범위기준 확정

2026.11.16 / 작가 확정 기준

AI가 스스로 살아가는 이야기가 아니라, 자매가 AI 아바타를 만들고 운영하는 이야기입니다.

아바타는 인간 자매의 사회적 페르소나입니다. 자매가 SNS를 직접 운영하며 상황을 정해 AI에게 작성을 맡기더라도 선택과 통제의 주체는 자매입니다. 이름은 Luxy로 통일합니다. 이전 Ruxy 표기는 오타였습니다.

동생 · 제작 과정을 하루하루

조용하지만 호기심 많고 끈기 있는 인물. 처음에는 원대한 계획을 밝히고, 이후에는 학습 결과를 보며 기대·초조함·침묵·작은 기쁨을 기록합니다. 성과가 없는 날에는 ‘…’만 남기는 표현도 가능합니다.

언니 · 기획하는 SNS

야무지고 계획적인 인물. 프로필부터 자신의 감각과 기획을 반영하고, 매력적인 디자인과 유용한 정보를 통해 영향력을 쌓습니다. 현실의 디자인 도구·무료 교육·디지털 시민 교육 등을 작품 세계에 어울리게 소개할 방향입니다.

1 epoch = 작품 속 1일은 캐릭터 본학습이 시작된 뒤에 적용합니다. 그전에는 모델 선택, 자료 제작, 기초 실험의 주요 작업을 하루에 하나씩 기록합니다. 실제 실행 시각과 작품 속 날짜는 별개입니다.

이번 공개 범위는 아바타를 만드는 과정과 SNS 운영까지입니다. 큰 사건과 결말은 다음 프로젝트로 분리합니다. 어린 시절 자매의 직접 대사와 제작 과정은 작가의 서사 기준으로 다룹니다.

loss가 감정을 뜻하는 것은 아닙니다. 실제 학습 관찰 → 인물이 받아들이는 해석 → 작가가 선택한 게시물로 구분합니다. ‘선을 인식했다’ 같은 캐릭터 표현은 모델의 이해 능력을 입증한 기술 평가와 구분합니다.

캐릭터를 학습하기 전, 동생의 준비 일지

동생이 자기 그림으로 AI를 만들어 보겠다고 마음먹은 날부터, 작품 속 하루에 주요 작업 하나를 배치합니다. 여러 장을 그리는 작업은 그림 수와 하루 작업량에 맞춰 여러 날로 나눕니다. 선·도형 기초 학습은 이 준비 일지의 작업이며, 실행 횟수를 작품 속 날짜로 바꾸지 않습니다.

아래는 2120년 1월 1일 시작을 가정한 편집 초안입니다. 날짜와 작업량은 확정된 작품 설정이나 실제 작업 소요 시간이 아닙니다. 하루에 그림을 그리거나 검수하는 시간은 4시간으로 잡았습니다.

기록에서 작품으로

끊겨도 이어가는 학습

03기술 문서를 읽을 때의 검증 경계기록

내용 업데이트 · 2026-11-12 20:42 (한국시간) · 변경 기록

호환성·시간·비용

SD와의 완전 호환, 고정 시간 내 학습 완주, 고정 GPU 메모리·컴퓨팅 단위 소비는 현재 검증된 결과가 아닙니다. 실제 구조, 장치 배정과 실행 로그를 기준으로 판단합니다.

권리·학습 해석

직접 제작한 데이터도 사용 도구·자산의 출처와 이용 조건을 확인합니다. ‘저작권 위험 0%’를 보장하지 않습니다. 과적합과 모델 붕괴를 동일시하거나 학습 손실을 인격·감정·성장률로 읽지 않습니다.

초기 예시 코드의 UNet 한 번 호출은 완전한 확산 샘플링과 다릅니다. 반복 노이즈 제거, 조건 입력, 저장·재개와 품질 평가를 각각 시험해야 합니다. 가중치만 저장한 파일은 최적화 상태까지 복구하는 체크포인트와 구분합니다.

04읽은 자료와 보존 원칙기록

내용 업데이트 · 2026-11-12 20:42 (한국시간) · 변경 기록

초기 프로젝트 아이디어, 10월 프로젝트 기획안, 기술 검토, 베이스 모델·파이프라인 가이드를 대조했습니다. 자료에는 작가의 요구와 AI가 작성한 설명이 함께 있으므로, AI 답변의 수치·보장 표현을 실제 성과로 취급하지 않습니다.

최신 사용자 결정 → 확인된 코드·실행 자료 → 날짜가 있는 원기획 → 과거 제안 순서로 구분합니다. 초기 문서의 의도를 삭제하지 않고 변경 이유를 남깁니다. 이전 문서를 자동 덮어쓰지 않습니다.

공유받은 원문과 이미지를 일괄 공개하지 않았습니다. 공개 페이지에는 프로젝트 설명에 필요한 요약과 현재 적용 기준만 반영했습니다.
