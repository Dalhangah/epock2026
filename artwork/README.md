# EPOCK SNS 인터랙티브 웹툰 — 독립 MOCK v0.1.0

기존 GitHub 아카이브와 무관한 별도 폴더. 공개·배포·GitHub 수정 없음.

## 실행

Python 3 사용 시 이 폴더에서 `python -m http.server 8765` 실행 후 `http://localhost:8765/` 접속. `file://`로 열면 fetch가 제한될 수 있음. 실제 가비아 호스팅과 연결되지 않음.

## 파일

- `index.html`: 접근성 있는 구조, 로컬 전용/미연결 안내
- `styles.css`: 모바일 우선 스타일과 레이어 컷
- `app.js`: 작품 날짜, 계정, 프로필, 게시물, 스토리, 로컬 댓글·좋아요, 알림 시뮬레이션
- `data/mock.json`: 모든 내용 MOCK, 외부 정보 카드 출처/URL 미확인 처리
- `data/ko-KR.json`, `data/en-US.json`: 언어별 예시 대사
- `assets/mock-sfx.png`: 투명 PNG 자리 표시 (웹폰트 제작 결과가 아님)
- `tests/test_static.py`: 파일/데이터 규칙 자동 검증

## 임시 정책 (미확정)

- `1 epoch = 작품 1일` 요구 반영. MOCK 앵커 2120-01-01은 임시. 실제 학습시각은 별도 `trainingAtReal:null`; 두 모델 epoch를 같은 학습량으로 매핑하지 않음.
- 날짜 선택 시 작품 속 정오 12:00 조회, 작품 시간대 없음. 정확한 시간대/시분 선택 미결.
- 스토리는 `[게시시각, 게시시각+24시간)` 반개방 구간을 MOCK으로 사용. 경계 미확정.
- 댓글은 게시물별 누적 표시, 간단한 작성시각 정렬을 임시 사용. 공식 노출·정렬 정책 미확정.
- 미래 기록은 게시시각이 선택 시각 이후이면 비표시. 게시물 없는 날은 이전까지 공개된 피드를 보여주며 신규 게시물 없음 상태는 별도 표시되지 않음.
- 닉네임/댓글/좋아요는 localStorage 전용. 다른 관람객과 공유되지 않음. 비밀번호/토큰 저장하지 않음. 브라우저 저장소 삭제 시 사라짐.
- 테스트 버튼은 실제 네트워크 알림이 아니라 현재 브라우저의 메모리에 이벤트를 만든 후, 선택 갱신 시 localStorage에 기록함.
- 카운트다운 운영 기능 없음.

## 테스트 결과 (2026-11-16)

- Python 정적 데이터 계약 테스트 8건 통과.
- `node --check app.js` 구문 검사 통과.
- Playwright Chromium 브라우저 smoke 테스트 실행 시 실행 환경 정책으로 `net::ERR_BLOCKED_BY_ADMINISTRATOR` 발생. 따라서 모바일 실제 렌더·키보드·스크린리더·언어 전환·알림 상태 보존은 브라우저 실측 **미검증**. 테스트 스크립트는 재실행 가능하게 포함.
